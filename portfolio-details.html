E-commerce Security Assessment

March 15, 2024 Penetration Testing Confidential Client

An online retailer asked me to test their store before a major sales season. The goal was to find weaknesses an attacker could use to steal customer data or tamper with orders, and to fix them before launch.

Project Overview

The assessment covered the public website, the customer account area, the checkout flow and the admin panel. Testing followed the OWASP Top 10, combining automated scanning with manual testing of business logic such as discounts, cart totals and order history.

Key Highlights

  • 14 vulnerabilities found, 3 rated critical
  • SQL injection in product search fixed before launch
  • Broken access control on customer orders closed
  • Admin panel moved behind multi-factor authentication
  • Retest confirmed every critical issue was resolved

How the Testing Was Done

I started with reconnaissance and mapping every page and API endpoint, then used Burp Suite to intercept and modify requests. Each finding was confirmed manually, rated by risk and written up with steps to reproduce it and a recommended fix.

The most serious issues are rarely the clever ones. Here, a single unchecked order ID let any logged-in customer view other people's orders.

Antony Mwendwa
Penetration Tester

After the fixes were deployed, I retested the site to confirm each issue was closed. The client now runs a short security review before every major release.
